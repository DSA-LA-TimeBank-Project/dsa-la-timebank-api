# DSA-LA TimeBank API Project

The DSA-LA TimeBank API Project is an open source API that contains the business logic for the DSA-LA TimeBank.  This project is written in [.Net 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

## Requirements

- [.Net 8.0](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Docker](https://www.docker.com/) (recommended for easier setup)

**This project is still under active development.  Please check in regularily for updates.
